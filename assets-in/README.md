# assets-in (drop zone)

Put images and videos the owner generates or downloads here, saved with the exact filenames from `docs/artifacts/image-prompts.html` (also `docs/artifacts/image-prompts.md`).
An agent then resizes, compresses, moves them to `public/` and wires them into the pages. See `docs/context/06-media-and-assets.md`.
