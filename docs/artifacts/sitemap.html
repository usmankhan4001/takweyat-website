How it is built

Your documentsCleaned once, nothing reworded. Already done and checked.
Content filesOne file per plan and page, kept in the project.
Page templatesEight templates turn the files into 123 pages.
Static websiteFast, no database, published on Dokploy.
Designed PDFsMade from the same content, so they never drift apart.
Forms (volunteer, legal aid, partnership, press, newsletter, whitepaper) connect to n8n after launch. Urdu is not part of this version.
