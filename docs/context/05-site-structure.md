## Shared parts
- `Base.astro` wraps everything: head, `Header`, `<main>`, `Footer`, inline script (header solid on scroll, phone menu, word-fill, scroll reveals, count-up, phase toggles).
- `PageHead.astro`: opening band of inner pages (props title, lede, tone teal|raspberry|charcoal|olive, crumbs, tag).
- `Photo.astro`: photo/video slot. With `video` + `poster` it renders a muted looping `<video>`; otherwise a placeholder block with caption.
- `LeadForm.astro`: one form component; fields array drives it; honeypot `website`; posts JSON to `site.formEndpoint` or shows an email fallback.

## Menu content (mega menu, `Header.astro` → `menus`)
